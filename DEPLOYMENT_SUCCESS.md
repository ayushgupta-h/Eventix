## 🎯 How to Run

### Prerequisites
- Node.js installed
- MongoDB installed locally

### Quick Start
```bash
# Clone the repository
git clone https://github.com/ayushgupta-h/Eventix.git
cd Eventix

# Backend setup
cd backend
npm install
npm run dev

# Frontend setup (new terminal)
cd frontend
npm install
npm run dev

# Start MongoDB (new terminal)
mongod --dbpath C:\data\db

# Seed sample events
# Visit: http://localhost:5000/api/seed/events (POST request)
```
